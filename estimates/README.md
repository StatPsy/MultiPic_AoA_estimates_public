# Estimates
This directory contains the age-of-acquisition (AoA) norms for all 750 items of the MultiPic corpus, as well as anonymised raw study data and code used to derive those norms.

## data
Contains the final AoA norms, the anonymised raw survey data and the participants' metadata.

## src
Contains the source code for wrangling the data, calculating the AoA norms, analysing said data and norms and generating the participants' metadata.
